Semantic HTML Tags Used by CNN.com and BBC.com

CNN.com Findings

  • Uses <nav> for the top navigation menu and section navigation.
  • Uses <article> to represent news stories and article cards.
  • <aside> is not prominent on the homepage because supplementary content is often built using <div> or <section> elements with dynamic rendering.

BBC.com Findings

  • Uses <nav> for the main navigation and category menus.
  • Uses <article> for featured stories and individual news items.
  • Uses <aside> selectively for related information, sidebars, and complementary content.

Overall Observations

  • <nav> is consistently used on both websites to identify navigation areas, improving accessibility.
  • <article> is the primary semantic element used for self-contained news stories.
  • <aside> is less frequently used, with many supplementary sections implemented using generic containers like <div> or <section>.

Summary: Both CNN.com and BBC.com make extensive use of semantic HTML, particularly <nav> and <article>, while <aside> is used less frequently for complementary content.
